## Key Takeaways
- Build harnesses so features can be shipped and removed quickly as models and products change.
- Use composable primitives, such as a shared subscription tool for responding to events, instead of adding separate integrations for each event.
- Track model-behavior workarounds, or “shims,” centrally, and remove them when they stop firing.
- Run autonomous agents in the cloud when they need to work for hours or days; a laptop may sleep or go offline.
- Scope agent permissions and add guardrails to limit risky actions and unexpected costs.

## TubeOnAI Summary
> An agent harness is no longer needed to make strong models better at coding, but it remains essential for expanding agents into new tasks and providing reliable infrastructure, security, and efficiency.
