## TubeOnAI Summary
> AI will shift software engineering from manually writing code to specifying goals, orchestrating agents, and making architectural decisions. Developers should learn how agents work, manage their context and iteration, and protect them from prompt injection.

Advice
- Assign coding agents whole features, including codebase analysis, testing, and integration, rather than using them only for autocomplete.
- Write clear specifications of requirements and expected outcomes for agents instead of relying on prompts that models may interpret differently.
- Break goals into milestones, then direct agents toward completing them while retaining responsibility for architecture and critical decisions.
- Manage the context agents receive, including code, tools, skills, and external data sources.
- Build iterative loops into agent systems so they can work toward a human-defined goal without constant back-and-forth prompting.
- Learn how language models work, including their limits around estimating time and memory, to use them more effectively.
- Use reusable skills, automations, and sub-agents to provide project context, trigger actions, and delegate investigations.
- Run coding agents in disposable sandboxes where possible, reducing the risk that prompt injection exposes credentials or other sensitive data.
