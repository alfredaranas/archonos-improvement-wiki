The main presentation frames production AI as a systems problem rather than a pure model problem, emphasizing that context quality, permissions-aware retrieval, infrastructure decisions, and end-to-end tracing often matter more than upgrading to the latest model. A case study reinforces this by showing that inconsistent answers, latency, and rising token costs were solved through retrieval redesign, workflow observability, caching, and model routing rather than prompt changes alone. A final lightning talk introduces AGUI as an open protocol for connecting agents to front ends, arguing that standardized event streams and generative UI patterns are necessary because agents no longer fit the old request-response interaction model.
