## TubeOnAI Summary
> The speaker explains how to design agentic artificial intelligence systems by defining workflows, choosing between single and multi-agent architectures, and matching sequential or parallel patterns to the task.

Advice
- Define the expected inputs and outputs before designing the agents.
- Write every process step and its edge cases so the workflow can be turned into a clear standard operating procedure.
- Do not automate a process until you can write a precise prescription for how it should work.
- Choose a single-agent system when the budget is limited and a multi-agent system when the stakes, complexity, and budget justify additional cost.
- Give every agent an LLM, the tools it needs, and a system prompt containing its rules and instructions.
- Use more capable reasoning models or a reason-and-act loop when a single agent makes mistakes.
- Isolate and compress the information each agent needs instead of placing all available context into one prompt.
- Use sequential patterns for fixed, repeatable workflows and parallel patterns for independent analyses that can run simultaneously.
