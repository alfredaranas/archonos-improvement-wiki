## TubeOnAI Summary
> - Multi-agent workflows in Antigravity rely on defining each agent’s role, responsibilities, and limits, then having an orchestrator delegate work to the right specialist. - Create a .agent folder in the workspace to define custom agents, and a skills folder for reusable capabilities that can be assigned to one or more agents. - Give agents clear identities as well as roles: the example team includes David as orchestrator, Laura as software engineer, Mike as technical researcher, Sarah as marketer, Toby as quality assurance engineer, and Eli as code reviewer. - Specify each agent’s scope so responsibilities do not overlap. For example, Mike researches and recommends but does not write code; David delegates implementation to Laura, research to Mike, and marketing copy to Sarah. - Add constraints that reduce unsupported claims and scope creep. Mike is told to cite sources or reasons, include significant trade-offs and risks, and avoid presenting opinions as facts. - Standardize agent outputs to fit the work: Mike’s research reports should explain what was investigated and why, compare options with pros and cons, and include relevant sources and metrics. - The same agent setup can be duplicated for GitHub Copilot or Claude alongside Antigravity. The speaker says their instructions can define which agents may communicate or delegate to one another.
