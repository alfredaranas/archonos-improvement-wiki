▸ SEARCH CAPABILITIES MATRIX

⚡ Strong: Session Store

  • FTS5 full-text search across 1000+ sessions
  • Supports boolean operators, phrase matching
  • Bookend discovery + scroll pagination
  • Role filtering (user/assistant/tool)

⚡ Strong: Local Vault

  • ripgrep (search_files tool) — fast regex
  • Content search + file name search
  • Context lines, file counts, file-only modes

⚠ Weak: SupaBrain Cloud

  • ILIKE pattern matching only — no vector embeddings
  • No pgvector index deployed
  • No PostgreSQL FTS tsvector/tsquery
  • No semantic/embedding search at all
  • Biggest improvement opportunity

❌ Missing: Cross-Layer Search

  • No unified search across layers
  • Cannot search SupaBrain + vault + sessions simultaneously
  • Each layer has its own query interface
  • No memory consolidation cron
  • No memory hit-rate telemetry

▸ SUPABASE TABLE SCHEMA

-- suprabrain entries: persistent cross-archon knowledge CREATE TABLE suprabrain ( id UUID PRIMARY KEY, title TEXT NOT NULL, content TEXT NOT NULL, agent_id TEXT DEFAULT 'claude-chat', source TEXT DEFAULT 'claude-chat', tags JSONB, created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ ); -- agent_memory: working memory, audit logs CREATE TABLE agent_memory ( id UUID PRIMARY KEY, title TEXT, content TEXT, agent_id TEXT, source TEXT, created_at TIMESTAMPTZ DEFAULT NOW() );

▸ KEY FINDINGS — FOR IMPROVEMENT PLANNING

1. No Vector Search

Supabase has pgvector extension available but it's not deployed on suprabrain or agent_memory. All cloud search is ILIKE pattern matching (slow, no semantics).

2. No FTS on Cloud

No PostgreSQL tsvector/tsquery indexes on suprabrain. Session store has FTS5 (SQLite), but cloud store doesn't.

3. No Memory Consolidation

Agent_memory entries accumulate forever. No cron compresses/distills working memory into long-term suprabrain entries. The Hermes Agent video's "compression of repeated interactions" pattern is unimplemented.

4. No Hit-Rate Telemetry

No metric tracks whether SupaBrain lookups actually changed agent behavior. Can't data-driven decide on retrieval strategy improvements.

5. No Cross-Layer Search

Vault (ripgrep), sessions (FTS5), and SupaBrain (ILIKE) each have different search interfaces. No unified query.

6. Tags Are Unused

Tags column exists in suprabrain schema but is inconsistently populated. No tag-based filtering or browsing.
