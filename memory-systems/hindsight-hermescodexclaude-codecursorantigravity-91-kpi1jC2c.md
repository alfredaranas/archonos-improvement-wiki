Advice
- Give agents explicit rules for what information is worth saving, when to retrieve memories, what private information must not be saved without authorization, and how to handle outdated memories.
- Let agents save non-sensitive information on their own only when ongoing authorization allows it.
- Have agents query long-term memory for questions about personal preferences, past project decisions, future ways of working, or cross-device continuity when the current session lacks reliable information.
- Do not let agents treat project identity files as a substitute for memories of a user's actual preferences and decisions.
- Avoid requiring a memory lookup on every turn, which can add unnecessary latency and cost.
- Verify tool-call records, not just answer quality, to confirm an agent actually retrieved shared memories.
- Test how the system handles decisions that change or conflict over time; the creator has not yet verified this.
