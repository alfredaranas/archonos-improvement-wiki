## Key Takeaways
- **💡 Three memory types are distinguished for AI agents’ dynamic context windows** — Fact memory stores discrete facts such as deployment details like “US West 1”.
- **🔥 Fact memory requires confirmation before promotion** — The intent is to avoid storing uncertain or unverified details as reliable knowledge.
- **🧠 Episodic memory should be summarized and made searchable** — Past procedures and successful resolutions are turned into summaries rather than kept only as raw logs.
- **🔎 Hybrid search is positioned as the retrieval method for episodic memory** — It is used to find runbooks, use cases, and similar historical problem-solving episodes.
- **🛠️ Trace memory supports replay and memory creation** — Replays can be generated from this record for debugging or review.
