## Summary

Agents differ from chatbots by executing autonomous workflows with the DATA loop—Diagnose, Assemble, Take action, Assess. The loop enables continuous self-improvement and learning, whereas chatbots require pull-based prompting. Use the 3R rule (Repetitive, Rules-based, Returns) to identify workload suitability for agent deployment.

## Key Takeaways

- Agents autonomously execute full workflows with feedback loops (DATA: Diagnose→Assemble→Act→Assess); chatbots respond reactively to prompts
- Deploy agents only for tasks meeting 3R criteria: Repetitive (weekly+), Rules-based (consistent I/O), and Return-positive (ROI > build cost)
- Define agent outcomes first, not execution steps; let AI determine method. Use Definition of Done (DOD) as measurable success criteria
- Agent identity focus (role/expertise clarity) outperforms general-purpose models; tight persona definition correlates with output quality
