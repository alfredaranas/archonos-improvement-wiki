## TubeOnAI Summary
> Connect an AI agent to a small set of useful tools, because the tools and integrations often matter more to its effectiveness than the choice of agent harness. The seven recommended tools cover code hosting, browser control, app integrations, current documentation, web search, web scraping, and persistent memory.

Advice
- Add only tools the agent needs; too many can clutter its context and lead it to choose the wrong tool.
- Connect the GitHub MCP server to let an agent manage repositories, review issues and pull requests, and test proposed changes.
- Use Browser Use when an agent needs to interact with web pages, especially in a headless environment; use its local browser option when access to your existing signed-in sessions matters.
- Use Composio to manage multiple app connections through one MCP server, and let the agent discover tools as needed rather than loading every integration at once.
- Use Context7 for current coding-framework documentation, Exa for finding relevant information, and Firecrawl for scraping pages you already know you need.
- Set up Mem0 if you want preferences and other useful memories to persist across sessions, agents, or machines.

Mentioned
- Tools: GitHub MCP server, Browser Use, Composio, Context7, Exa, Firecrawl, Mem0
- Agent harnesses: Claude Code, Codex, OpenClaw, Hermes
- Software: React, Google Flights, Slack, Gmail, Notion, Google Drive,
