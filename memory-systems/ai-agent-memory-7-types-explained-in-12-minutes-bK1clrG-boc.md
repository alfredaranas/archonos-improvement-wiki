## TubeOnAI Summary
> The speaker explains seven practical AI agent memory types and how to choose, retrieve, update, and schedule information so an agent receives the right context for each decision.

Advice

- Keep only the information needed for the current task in working memory, because context windows are limited and extra context increases cost, latency, and distraction.
- Save stable facts in semantic memory only when they should remain useful across conversations, and assign each fact an owner, scope, and lifetime.
- Verify information from emails, websites, and tools before treating it as trusted semantic memory.
- Replace outdated facts and let users correct or delete important memories.
- Retrieve external information with the method that fits the question, then filter results by user, team, time period, relevance, date, and permissions.
- Test retrieval separately from the final answer, because a confident response does not prove that the correct memory was found.
- For future tasks, store the required context, status, approvals, and trigger, then use clear states such as pending or completed to prevent duplicate actions.
- Before choosing a database, decide what must survive, how it should return, when it should be updated or forgotten, and whether it must wake the system later.

- Tools and methods: exact lookup, keyword search, embed
