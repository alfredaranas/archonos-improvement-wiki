## Key Takeaways
- Production RAG fails when teams treat it as a single vector search demo rather than a governed retrieval system with orchestration, evaluation, and business accountability.
- The talk argues that reliable agentic RAG requires query-aware retrieval strategies such as BM25 for exact identifiers, hybrid retrieval for mixed semantic and lexical queries, GraphRAG for relationship-heavy reasoning, metadata and hierarchical chunking for context preservation, and caching for latency and cost control.
- It also maintains that systems should detect low confidence, escalate to humans, validate evidence, and route requests across APIs, search indexes, graphs, and caches instead of sending every request through one generic RAG pipeline.

## Core Thesis
Production-grade agentic RAG needs orchestration, evaluation, and KPI-linked retrieval design rather than a single demo-style vector search pipeline.
