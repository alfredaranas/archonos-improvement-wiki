## Key Takeaways
- Keep `soul.md`, `user.md`, `memory.md`, and `AGENTS.md` concise because they can consume context in every chat.
- Prefer `AGENTS.md` for agent instructions when you want compatibility across different agent tools.
- Disable unused tools and move instructions that are only occasionally relevant into skills, so they load on demand.
- Use an external memory provider when agents need to retain useful information across chats, profiles, or tools; interview the agent to seed it with your preferences and working style.
- Put reviewed project knowledge in an Obsidian vault or similar file system, and have agents retrieve relevant notes instead of loading the whole vault into each chat.
