## Key Takeaways
- **🔥 Chat vs Agents — the productivity shift** — Chat = question → answer (consultant-like); Agents = goal → result (hire-to-execute).
- **💡 Agent loop (core runtime)** — Three-step loop: Observe → Think → Act, repeated until the goal criteria are met.
- **🧭 Four tuning levers that make agents useful** — Context: the facts and documents the agent reads before starting.
- **📁 Context: markdown-first, owned knowledge assets** — Use markdown (.md) files (about.md, idealcustomer.md, brandvoice.md) because they ingest cleanly.
- **🛠 Tools / MCPs (connectors) — enable action on external systems** — MCP = translator/API layer that lets agents interact with third‑party tools (email, calendar, CMS, ads).
- **🔎 Useful connector/tool types (illustrative)** — Scraper marketplace (Apify-like): prebuilt scrapers for YouTube, Instagram, LinkedIn, Google Maps.
- **🧠 Skills = SOPs for agents (most important single technique)** — Skills are markdown SOPs that tell the agent step-by-step how you want a task done.
- **🔁 Progressive disclosure and session context limits** — Agents load name + descriptions of many skills into session; full skill contents are loaded only when called.
