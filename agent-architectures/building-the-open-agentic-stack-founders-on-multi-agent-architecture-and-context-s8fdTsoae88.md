## TubeOnAI Summary
> The panel argues that reliable agent systems will combine deterministic workflows, flexible multi-agent steps, strong context management, security controls, and model or framework flexibility rather than relying on a single pure-agent design.

Advice
- Use deterministic backbones for workflows, then add as much agent behavior as each step needs.
- Give agents the exact context, permissions, tools, business rules, and source data required for their task.
- Run agent platforms in a company-controlled cloud with private databases, monitoring, persistence, and user-matched permissions.
- Use observability and evaluations to improve agent accuracy, and design user review into tasks where perfect reliability is unnecessary.
- Use sub-agents when a main agent must work across many specialized sources, such as Slack, documents, PDFs, and databases.
- Add sandboxes, tests, access controls, and standard engineering practices before expanding coding-agent use.
- Control coding-agent costs with an LLM gateway, per-person budgets, usage monitoring, model selection, and optimization rather than unrestricted token consumption.
- Design libraries, documentation, skills, and interfaces so coding agents can install, understand, and use them directly.
