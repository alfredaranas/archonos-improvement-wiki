## Key Takeaways
- Start with Hermes’ free onboarding model if you are new to agents and want help setting things up; skip it if you prefer to run locally from the beginning.
- Use the model picker’s hardware suggestions, then choose a model that fits your available memory with extra room for context.
- Keep an eye on memory use while a model loads; exceeding available memory can make it run much more slowly.
- Turn on persistent memory and user profile in Memory and Context settings if you want Hermes to remember your projects and preferences.
- Use Docker as the terminal execution backend to isolate code execution from the rest of your computer.
